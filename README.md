# しめきりカレンダー（懸賞・ポイ活）

見つけた懸賞・ポイ活キャンペーンの**締切**をまとめて、サイト・スマホのカレンダー・X に届ける仕組みです。
**どれを載せるかはあなたが決め、締切の読み取りと掲載は自動**で行います。スマホだけで回せます。

## 毎日の使い方（スマホでOK）

1. 良さそうなキャンペーンを見つけたら、GitHub のリポジトリで **Issues → New issue →「キャンペーンを登録」**
2. 公式ページのURLと種類（懸賞／ポイ活）を入れる。ひとこと紹介は自分の言葉で（空でも可）
3. 1〜2分で下書きがコメントで返ってくる（締切・賞品・当選人数・還元率・条件を自動で読み取り）
4. 内容を確認して、Issue に **公開** とコメント → サイトとカレンダーに載り、X に新着として投稿
   - 直したいとき：Issue を編集（フォームに書いた値が自動読み取りより優先）
   - 載せるのをやめるとき：**取り下げ** とコメント
   - ページが更新されたとき：**再読み取り** とコメント

自動で投稿・更新されるもの:

| タイミング | 内容 |
|---|---|
| 公開したとき | X に【新着・懸賞】などを投稿 |
| 毎朝 7:11 | X に【今日締切】 |
| 毎夕 17:37 | X に【締切リマインド】（今日の残り＋明日） |
| 毎晩 0:03 | 締切を過ぎたものをサイトから外す |

サイトには「スマホのカレンダーに入れる」リンクがあり、登録した人のスマホには締切の前日と3時間前に通知が届きます。

## 規約・法律まわりで守っていること

- **読みに行くのは、あなたが登録したページ1枚だけ**。一覧ページの自動収集はしません。`robots.txt` で禁止されているサイトは読まず、フォームに書いた値だけで下書きを作ります
- **本文や画像はコピーしない**。載せるのは締切・人数などの事実と、あなたが書く一言紹介だけです。詳しい内容は公式ページへのリンクで案内します
- **広告には必ず「PR」表記**。アフィリエイトリンクを入れたものはボタンに PR が付き、サイトの下に「アフィリエイト広告を利用しています」と表示します（ステマ規制への対応）。リンクには `rel="sponsored"` も付けます
- **PR TIMES のような配信サイトの記事を自動で集めて載せる使い方はしないでください**。PR TIMES は許可のない営利目的の利用を規約で禁じています
- アフィリエイトの広告主によっては「SNSへのリンク掲載禁止」などの条件があるので、提携するときに確認してください
- 当選・還元を保証する書き方はせず、「最新の条件は公式ページで」と案内します（サイトとカレンダーに表示済み）

## セットアップ

### 1. GitHub

1. 新しいリポジトリを作り、このフォルダの中身をすべてアップロード
   - 無料プランで GitHub Pages を使うなら公開（Public）リポジトリにします（掲載データは公開されますが、X のキーは Secrets に入れるので公開されません）
2. **Settings → Pages → Source** を「GitHub Actions」にする
3. **Settings → Secrets and variables → Actions**
   - Variables：`SITE_URL` に公開先（例 `https://ユーザー名.github.io/リポジトリ名/`）
   - Variables：最初は `DRY_RUN` = `1`（X に投稿せず、Actions のログに文面を出すだけ）
4. Actions タブで shimekiri を開き **Run workflow** → サイトが公開されるのを確認

### 2. X（投稿もしたい場合）

1. bot 用アカウントを作り、プロフィールに「個人のまとめ・自動投稿あり」とサイトのURLを書く
2. 開発者コンソールでアプリを作り、権限を **Read and write** にしてから、API Key／Secret と Access Token／Secret を発行
3. Secrets に `X_API_KEY` `X_API_SECRET` `X_ACCESS_TOKEN` `X_ACCESS_TOKEN_SECRET`
4. クレジットを購入し、月の上限を低めに設定
5. ログで文面を確認できたら、Variables の `DRY_RUN` を消して本番開始

投稿には既定でリンクを入れません（URL付きは1件0.20ドル、なしは0.015ドル）。
朝の投稿だけサイトのURLを付けたいときは、Variables に `POST_SITE_LINK` = `1`。

### 3. アフィリエイト

ASP（A8.net などの仲介サービス）に、公開したサイトのURLで登録します。審査に通ったら、提携した広告のリンクを登録フォームの「アフィリエイトリンク」欄に入れるだけで、PR 表記つきのボタンになります。
審査では、ある程度の掲載数と独自の内容（一言紹介）が見られることが多いので、しばらく掲載を続けてから申し込むのがおすすめです。

## 調整できること（Variables）

| 名前 | 内容 | 既定 |
|---|---|---|
| `SITE_TITLE` | サイト名 | しめきりカレンダー |
| `SITE_URL` | 公開先のURL（カレンダー登録リンクに使う） | なし |
| `DRY_RUN` | `1` で X に投稿しない | なし |
| `POST_SITE_LINK` | `1` で朝の投稿にサイトURLを付ける | なし |

投稿時刻は `.github/workflows/shimekiri.yml` の cron（UTC表記。日本時間 −9時間）。

## パソコンで試す

```bash
pip install -r requirements.txt
python -m unittest discover -s tests          # テスト
python -m shimekiri add https://... --kind 懸賞 --summary "一言" --publish   # 手で1件登録
python -m shimekiri build --out public         # public/index.html を作る
python -m shimekiri post morning --dry-run     # 投稿文を確認
```
